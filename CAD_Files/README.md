# CAD Dosyaları

Bu dizin, Kart Dağıtıcı Makine'nin (CDM) mekanik bileşenlerine ait tüm 3B parça ve montaj (CAD) dosyalarını içerir.

## Bölümler

- **[Upper_Parts](Upper_Parts/)**: Üst bölme parçaları (kart haznesi, karıştırma ve itme mekanizması).
- **[Middle_Parts](Middle_Parts/)**: Orta bölme parçaları (fırlatma mekanizması ve OLED ekran yuvası).
- **[Lower_Parts](Lower_Parts/)**: Alt bölme parçaları (motorlar, sensörler, devre ve konnektör montaj aparatları).
